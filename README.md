# Roblox Feature Pack (Test Assignment)

Набор игровых механик, реализованных в Roblox Studio (Lua) в формате тестового задания.

---

## Как проверить работу
- Скрипты для каждого задания лежат в отдельных папках или сервисах.  
- Включены финальные версии (объединяющие все пункты).  
- При необходимости можно включить отдельные варианты (например, Zadanie1.1 или Zadanie3.1-3.2) — они тоже работают корректно.  

---

## Задание 1 — Счётчик и телепорты
**ТЗ:**  
1. Счётчик увеличивается только при первом заходе на плиту.  
2. Если игрок стоит 2 секунды на платформе — его телепортирует на SpawnLocation.  
3. Каждый 5-й телепорт заменяется на смерть игрока.  

**Реализация:**  
- Скрипты `Zadanie1.1`, `Zadanie1.2` и финальный `Zadanie1.3` лежат в *ServerScriptService*.  
- По умолчанию включён `Zadanie1.3`.  
- Чтобы избежать багов с `Touched/TouchEnded` (каждая часть тела игрока вызывает событие отдельно), использован более надёжный вариант со счётчиком и флагами.

## Задание 2 — GUI + сохранения
**ТЗ:**  
1. GUI должен выглядеть хотя бы минимально красиво.  
2. Каждое 20-е нажатие убивает игрока (логика на сервере).  
3. При повторном входе счётчик сохраняется и продолжается.  

**Реализация:**  
- Локальный скрипт `Zadanie2` находится в *StarterPlayerScripts*.  
- Для обмена данными использованы `RemoteEvent` в *ReplicatedStorage*.  
- Серверная логика (`Zadanie2`) лежит в *ServerScriptService*: принимает ивенты, обрабатывает, сохраняет и загружает клики через DataStore.  
- Подсчёт очков на клиенте оставлен как в заготовке, но отмечено, что корректнее было бы делать это на сервере.

## Задание 3 — KillBlock + Checkpoints
**ТЗ:**  
1. Красная платформа убивает игрока.  
2. Белые парты работают как чекпоинты.  
3. При активации нового чекпоинта предыдущий исчезает; когда исчезнут все — появляются снова.  

**Реализация:**  
- Все скрипты находятся в папке *Zadanie3*.  
- Вариант «простой» (`Zadanie 3.1-3.2`) есть отдельно, но отключён.  
- Полноценный вариант — `Zadanie 3 (полностью)`, сделан через **теги чекпоинтов**.  

![Задание 3](./Task3.gif)

## Задание 4 — Tweening и анимация объектов
**ТЗ:**  
1. Объект `mover` должен двигаться между `pos1` и `pos2`.  
2. Объект `spiner` вращается вокруг вертикальной оси.  

**Реализация:**  
- Скрипт `Zadanie4` лежит в папке *Zadanie4*.  
- Движение реализовано через TweenService.  
- Вращение — через `PivotTo` (корутины).
